    Shortcuts

    ⌘V outside the editorAppend to the current note
    ⌥N or nNew note
    /Search
    j / kNext / previous note
    ⌘EToggle Write / Read
    ⌘B ⌘IBold, italic
    ⌘KMake the selection a link
    Tab / ⇧TabIndent / outdent lines
    EscLeave the editor, clear search

    In Read mode, click any inline code to copy it, or hover any line, list item or code block for its copy button. ⇧-click a copy button to copy the markdown source instead.
